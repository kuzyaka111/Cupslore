# Чаши — база знаний

Статический справочник сеттинга из двух Discord-выгрузок. Три верхние вкладки:

- **Источники:** два сервера, 33 канала и ветки, 119 сообщений, исходные даты и ссылки на Discord, 81 изображение.
- **Информация:** 22 тематические статьи, карты, история, народы, религии, организации и сюжетные записи.
- **Расхождения и проблемы:** 29 записей с сопоставлением формулировок и ссылками на сообщения.

## Состав источников

Все перечисленные истории прочитаны до конца. Во втором корпусе девять запросов списков архивных приватных веток вернули 403: наличие дополнительных закрытых материалов не проверено. Удалённые и скрытые от бота сообщения не восстанавливались.

Дата публикации или правки сообщения не устанавливает приоритет канона. Разные версии сохраняются со ссылками. Сюжетные планы Рея помечены как авторские заметки со спойлерами. Старые числовые правила не переносятся автоматически в «Легенду в Тумане».

## Файлы

- `index.html`, `style.css`, `app.js` — интерфейс без фреймворков, внешних библиотек и сборщика.
- `data/content.json` — редактируемые источники, статьи и вопросы.
- `data/content.js` — те же данные для загрузки без сервера и fetch.
- `assets/` — локальные копии изображений для просмотра. Полноразмерные оригиналы остаются в исходных ZIP.

После редактирования JSON синхронизировать JS:

```sh
python scripts/sync_data.py
python scripts/check.py
node --check app.js
```

## Публикация

Для GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
На странице Pages GitHub покажет адрес готового сайта. После активации изменения в main публикуются автоматически.

Для локального просмотра открыть `index.html` или собрать копию `python scripts/build.py`.

Тексты источников сохранены без исправления опечаток. Мелкие топонимы внутри карт не распознаны в отдельный текстовый индекс. Прямые ссылки на Discord требуют прав доступа к серверу; опубликованные тексты доступны читателям сайта.
